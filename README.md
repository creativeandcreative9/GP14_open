# ポーズ工房の配布

ポーズ工房の最新版は [Releases](https://github.com/creativeandcreative9/GP14_open/releases/latest) からダウンロードできます。

`S_PoseKoubo_v...unitypackage` を Unity 2022.3 プロジェクトへ取り込んでください。更新するときは Unity の取り込み画面ですべての項目を選びます。

1.0.7以前からは、1.0.8を一度手動でImportしてください。1.0.8以降は、ポーズ工房の［更新を確認］と［更新］を使えます。自動確認は標準でONで、設定からOFFにできます。新しい版があっても自動でImportはしません。更新前に作業を保存してください。

導入先は `Assets/S_PoseKoubo` です。旧 `Assets/PoseKobo` / `Assets/SanaPoseKoubo` は、Unity内で `S_PoseKoubo` に名前変更してから取り込みます。Packages版とは併用せず、Packages版はPackage Manager / VCCで更新してください。

使い方は [ポーズ工房 使用手引書](https://creativeandcreative9.github.io/GP14_manual/GP14%E4%BD%BF%E7%94%A8%E6%89%8B%E5%BC%95%E6%9B%B8.html) を参照してください。
