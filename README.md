# ポーズ工房の配布

## 1.0.20への初回更新

作業を保存してプロジェクトをバックアップし、ポーズ工房の窓を閉じます。**Unity の Project ウィンドウで `Assets/S_PoseKoubo` を `GP14_PoseKoubo` に名前変更してから、新版を手動で Import してください。** さらに前の `SanaPoseKoubo` / `PoseKobo` からも同じ新しい名前へ変更します。写真・動画・保存ポーズはフォルダごと保持し、削除しないでください。

配布物は [Releases](https://github.com/creativeandcreative9/GP14_open/releases/latest) から取得します。`S_PoseKoubo_v…unitypackage` を Unity 2022.3 プロジェクトへ取り込み、更新項目をすべて選びます。ファイル名は以前の更新機能との互換性のため継続していますが、導入先は `Assets/GP14_PoseKoubo` です。初めて入れる場合はそのまま Import できます。

初回の名前変更後は旧版の［更新］ボタンでは進めない場合があるため、上記の手動Importを行ってください。新版導入後は［更新を確認］と［更新］を使えます。自動確認は標準ONで、設定からOFFにできます。ダウンロード・Importは利用者が選びます。

新旧フォルダが両方ある場合は、バックアップし、写真等の保存データを確認してから整理します。Packages版は Package Manager / VCC で更新してください。

使い方は [ポーズ工房 使用手引書](https://creativeandcreative9.github.io/GP14_manual/GP14%E4%BD%BF%E7%94%A8%E6%89%8B%E5%BC%95%E6%9B%B8.html#update-folder) を参照してください。
