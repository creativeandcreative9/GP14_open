# 3D 創作スタジオ

Unity（VRChat 用アバター）で、ポーズ・メッシュ・きがえ・ボーンを作る道具のセットです。

制作: アプリ工房ルナ

## 入れかた

1. [Releases](https://github.com/creativeandcreative9/GP14_open/releases/latest) から `3D_CreativeStudio_v…unitypackage` をダウンロードします。
2. Unity 2022.3 のプロジェクトへ Import します（すべて選択）。
3. メニュー `Tools` から、使いたい工房を開きます。

ダウンロードしたファイルは、`SHA256SUMS` と照らして確かめられます。

## 利用規約

著作権は、作者（アプリ工房ルナ）が持ちます。
コードのすべてまたは一部の流用を禁じます。

※ 他の人の素材（衣装・アバターなど）を改変したものを販売できるかは、その素材の規約に従ってください。

## 更新のしかた

窓の［更新を確認］から、新しい版を取り込めます。取り込むときは、Unity のプロジェクトをバックアップしてから行ってください。写真・保存ポーズ・編集データのフォルダは消さないでください。

## 以前のポーズ工房（1.0.8〜1.0.20）をお使いの方

以前の更新機能は、この新しい配布の形に対応していません。自動確認で「更新情報を確認できません。」と出ますが、作業が壊れることはありません。

一度、BOOTH の無料ページから 3D 創作スタジオを入れ直してください。そのあとは、新しい更新機能で更新の通知が届きます。

入れ直す前に、プロジェクトをバックアップしてください。`Assets/S_PoseKoubo` が残っている場合は、Unity の Project ウィンドウで `GP14_PoseKoubo` に名前変更してから Import します。写真・動画・保存ポーズは、フォルダごと残して、削除しないでください。
